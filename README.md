## Quick Start

1. Press **`Win + X`** and open **Terminal (Admin)** or **Windows PowerShell (Admin)**.
2. Paste the command below and press **Enter**:

```powershell
irm is.gd/BetterTitus | iex
```

> **Note:** BetterTitus automatically creates a Windows System Restore Point before applying deep system modifications, allowing you to safely revert changes at any time.

---

## Exclusive: Per-Game Optimization

Unlike standard system tweakers that only apply global changes, **BetterTitus** includes a dedicated **Gaming Options** module to fine-tune individual executables without affecting daily desktop usage:

* **CPU & Core Control:** Set process priority and custom CPU core affinity per game.
* **GPU & Display Tweaks:** Configure high-performance GPU preferences and selectively disable Fullscreen Optimizations (FSO) to minimize input latency.
* **Quick Revert:** Isolated profiles for competitive shooters and single-player titles that can be toggled or restored in seconds.
