## Quick Start

1. Press **`Win + X`** and open **Terminal (Admin)** or **Windows PowerShell (Admin)**.
2. Run:

```powershell
irm is.gd/BetterTitus | iex
```

> Automatically creates a System Restore Point before applying tweaks.

---

## Exclusive: Per-Game Optimization

Fine-tune individual games without altering global Windows behavior:

* **CPU & Core Affinity:** Custom process priority and core assignment per executable.
* **GPU & Input Lag:** High-performance GPU preference and selective Fullscreen Optimizations (FSO) toggle.
* **Isolated Profiles:** Per-title tweaks with instant revert.
